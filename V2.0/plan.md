# План разработки: VestaScan Pro V2.0
## Рамки (зафиксировано 2026-10-29)
- **База V2.0** — объединение двух проектов: VestaScanPro (наш: транспорт v1.4.1 с рукопожатием, `core/theme.dart` + `core/constants.dart`, экран-сниффер с AUTO-DUMP) и `lada_vesta_scanner` (рабочий старый: провайдер опроса, экраны Датчики/Журнал/Коды, JSON-профиль ЭБУ, trip_calculator, OTA, ИИ-Снапшот).
- Железо/протокол: ELM327 v1.5 (SPP), CAN 500 кбит/с 11-бит, ЭБУ Итэлма М86, калибровка I765BJ56v3.
- Транспорт: `connect()` → `_waitForSocketReady` (AT→`>`) → проверяемый init (`okCritical >= 6`). Тайминги: дефолт 1200/120; multi-frame (0904, 22F1xx, 22F191/195, 222001..003, 220401..003) — 2000/250.
- Данные: честность (никаких заглушек); расчётные величины помечаются («Воздух (расчётный)»).
- Лимит 400 строк/файл; цвета — только `AppColors`.
