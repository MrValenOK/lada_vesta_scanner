## Как читать дампы

- `→ CMD` / `← ОТВЕТ` — обмен через сниффер (ответ после `_cleanRaw`: без эха и `>`, строки через ` | `).
- `N:...` — кадры многокадрового ответа ELM (0:, 1:, 2:); первая строка вида `01A`/`043` — точная длина payload в hex.
- `Δ[i,j,...]` — индексы payload-байтов, изменившихся с прошлого тика мониторинга (payload считается ПОСЛЕ префикса `62 00 01`).
- `010C` = `(A*256+B)/4` об/мин; `0104` = `A*100/255` %; `0105` = `A-40` °C; `0106/0107` = `(A-128)*100/128` %.
